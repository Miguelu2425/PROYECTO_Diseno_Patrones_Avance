# Matriz de Casos de Prueba

**Proyecto:** Plataforma Integral de Atención Ciudadana Municipal  
**Fecha:** Noviembre 2026  
**Entorno de Ejecución Automatizada:** Java 11 (Adoptium OpenJDK 21/25 en modo headless, repositorio en memoria).

---

## Convenciones de Estado
- **PASÓ (Automatizado):** Caso verificado al 100% mediante suites de pruebas unitarias o de integración en memoria sin intervención gráfica.
- **Pendiente de prueba manual:** Caso que requiere despliegue gráfico interactivo o instancia real de Microsoft SQL Server con credenciales locales.

## 1. Convenciones de Estado

- **OK:** Caso ejecutado y verificado al 100% de forma automatizada en memoria mediante suites de pruebas unitarias o de integración, sin errores ni excepciones no controladas.
- **Pendiente de prueba manual:** Caso que requiere interacción directa con monitor gráfico (pantalla física Swing) o una instancia física local de Microsoft SQL Server en ejecución.
